# Portfolio — Alessio Mura

Landing page del portfolio: una sequenza legata allo scroll in cui il nome si sgretola in pixel, diventa codice HTML, poi binario, e infine si ricompone nei progetti.

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Stack: Vite, React, TypeScript. Le animazioni sono scritte a mano su canvas 2D, senza librerie esterne.
